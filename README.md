# ES-2
Прототип экспертной системы, которая на основе исторических данных вертикального зондирования ионосферы позволяет:
1.	Определять фазы циклов критической частоты слоя F2 (минимум, рост, максимум, спад).
2.	Прогнозировать наступление экстремумов (максимумов и минимумов) с оценкой достоверности.
3.	Выявлять аномальные отклонения и объяснять их возможные причины.
